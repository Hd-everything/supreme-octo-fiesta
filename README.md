# Status HD

A Flutter app for preparing photos and videos for WhatsApp Status, with a premium dark interface and device-local appearance customization.

## Current features

- Cross-platform Flutter/Dart codebase for Android and iOS.
- Select a photo or video through the system media picker.
- Preview selected images and play/pause video previews.
- Trim a selected video range and split it into clips up to 30 seconds.
- Native Android MP4 remuxing and iOS AVFoundation passthrough export, where the source format supports it.
- Share the selected original file through the system share sheet without intentionally re-encoding it.
- Custom accent colors, AMOLED black mode, compact layout, and rounded/sharper surfaces.
- Appearance settings persist locally on the device.
- No account or media-upload backend is required for the core workflow.
- GitHub Actions builds an Android debug APK and an unsigned iOS simulator app on each push to `main`.

## Build locally

Install Flutter stable and the platform toolchain, then run:

```sh
flutter create --platforms=android,ios --org com.ptip --project-name statushd --overwrite .
flutter pub get
flutter analyze
flutter test
flutter run
```

The application ID generated by this organization/project name is `com.ptip.statushd`, separate from Fasmora's `com.ptip.pulse`.

## GitHub Actions artifacts

Open the repository's **Actions** tab, select **Build Status HD**, and download `statushd-android-debug` after the Android job succeeds. The iOS artifact is an unsigned simulator app for development inspection; it is not an installable iPhone IPA.

The Android artifact is debug-signed by the Android build tools. It is not a production release and does not use Fasmora's keystore. A production build can later use a dedicated Status HD signing configuration or reuse the same Android certificate securely through GitHub Actions secrets.

## iOS distribution

Building an iOS simulator app does not require App Store signing. To distribute an iOS app to a physical iPhone or the App Store, configure Apple signing and provisioning through a macOS/Xcode workflow. Never commit Apple certificates, provisioning profiles, keystores, or passwords to this repository.

## Video trimming note

Video segment export aims to avoid re-encoding where the platform/source permits. Lossless boundaries can align to nearby keyframes, and some source formats may fail to export. Original files are not overwritten. Temporary exported clips are stored in the app's temporary directory.

## Quality note

Status HD does not automatically transcode or compress the selected media. It hands the chosen file to the platform share sheet. WhatsApp and other destination apps can still recompress, resize, or otherwise process media after handoff; no third-party app can guarantee that WhatsApp preserves every original pixel or frame.

Status HD is an independent project and is not affiliated with WhatsApp or Meta.
